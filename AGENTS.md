# For AI assistants working in this repository

1. Read [CONTEXT.md](CONTEXT.md) first. It holds what ClinicOS is, what is built and
   live, every decision already made, the plan for what is left, and what is waiting
   on the owner.
2. Then read [CLAUDE.md](CLAUDE.md). Despite the name it applies to every assistant:
   the non-negotiable invariants, architecture, gotchas and house style.
3. Before you finish a piece of work, update CONTEXT.md (§3 Current state, §6 Plan,
   §7 Waiting on Ishaan, §10 History) so the next session starts where you stopped.

Do not ask the owner to repeat context that is already in those two files.
